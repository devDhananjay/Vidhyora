📁 Step 2: Copy Files to Project

Open Terminal and run these commands:

# Navigate to project
cd /Users/meondev/Desktop/VIDYORA

# Copy ring (adjust filename based on what you downloaded)
cp ~/Downloads/rose-gold-ring.glb public/models/rings/sample-ring.glb

# Copy bangle
cp ~/Downloads/golden-bangle.glb public/models/bangles/sample-bangle.glb

# Copy jewelry set for earrings & necklace
cp ~/Downloads/golden-jewelry-set.glb public/models/earrings/sample-earring.glb
cp ~/Downloads/golden-jewelry-set.glb public/models/necklaces/sample-necklace.glb
💡 Tip: If files downloaded with different names, replace the filenames in the commands above!

✅ Step 3: Verify Setup

Make sure everything is in place:

./scripts/verify-models.sh

You should see green ✅ checkmarks for all files!

🚀 Step 4: Test AR!

npm run dev
✨ Then:
  1. Open any product page
  2. Click "Try AR" button
  3. Toggle "3D Mode (Beta)" ON
  4. Show your hand/face to camera
  5. 🎉 See your 3D jewelry in AR!
